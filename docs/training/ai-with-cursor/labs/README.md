## Cómo leer cada lab

1. **Antes de empezar** — lo que ya debes tener abierto o acordado.
2. **Pasos** — hazlos en orden. No saltes verify.
3. **Verifica** — comprobación concreta (archivo, comando, pregunta al agente).
4. **Listo cuando** — checklist de salida de la sesión.

Si vas lento, el facilitador recorta el ticket, no pospone pasos a otra semana.
